Laboratory Exercises

Lab 1

User Interface Architecture

Exploration of structural UI layouts using native Android Studio Jetpack Compose components.

Reflection In Lab 1, I learned how to build and structure static user interfaces using fundamental layouts like Rows and Columns in Jetpack Compose. It was quite challenging at first because I had to get used to the Android Studio environment and understand how composables work without any multi-screen navigation.
Lab 2

State & User Interaction

Implementing state tracking frameworks to deliver dynamic real-time app interactions.

Reflection For Lab 2, I successfully built a functional CGPA calculator by learning how to handle user text inputs and state management. I implemented logical formulas to calculate credits and determine the user's dean's list status, which made the app highly interactive.
Lab 3

Material Design 3 Styling

Configuring consistent design tokens, specialized typography, and structural dynamic themes.

Reflection Lab 3 focused on UI styling, which became challenging when I had to download external configuration files from Google to set up a custom theme. Adjusting fonts and refining colors for components like cards was tedious, but it taught me how to properly implement Material Design 3.
Lab 4

Multi-Screen Navigation Flow

Engineering comprehensive Navigation systems integrated directly with a Shared ViewModel matrix.

Reflection In Lab 4, I progressed from a single-screen layout to a multi-screen app architecture by implementing Jetpack Compose Navigation and a Shared ViewModel. This allowed me to create the initial prototype for my flashcard and deck screens while securely managing state across screens.
Lab 5

Room Local Storage Engine

Compiling offline-first architectures using local object relational mapping databases.

Reflection Lab 5 introduced a major technical challenge where I faced persistent Gradle build errors caused by the KSP plugin configuration. After resolving the issue, I successfully mastered Room persistent storage by implementing data access objects (DAOs), repositories, and entities for a working local database.

Reflection & Learning Journey

My learning journey began with struggles in Lab 1 and 2, where I first learned to structure static layouts using Rows and Columns, and later built a functioning CGPA calculator with user text inputs. The difficulty increased during Lab 3 and 4 as I learned to manage custom color themes, font stylings, and eventually implemented multi-screen navigation using a shared ViewModel for the core flashcard screens. Lab 5 introduced a tough technical hurdle with ksp errors in the build gradle, but overcoming it taught me how to properly implement Room persistent storage using DAOs and repositories. Finally, Project 1 and 2 tied everything together, pushing me to upgrade my skills from basic layouts into creating a complete, smart application with live REST APIs, Firestore cloud functions, and Camera AI features.
